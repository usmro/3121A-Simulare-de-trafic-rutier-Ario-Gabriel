Rules

Traffic Lights

🔴Each intersection has a random 1–3 tick red/green cycle, re-randomised every phase.
🎲Starting state randomised each run.
⏱Lights flip at end of tick — vehicles always see the full phase.

Collisions

💥Two+ vehicles on the same street in the same tick = collision logged.
🔄Logged as an event only — vehicles keep moving.

Congestion

📊Each street gets a random congestion value 1–10 at run start.
⏳Congestion above threshold adds wait ticks. Delivery is immune.

Road Network

⬛3×3 grid: 9 intersections (A–I), 12 bidirectional streets.
🎯All vehicles spawn and target corners only: A, C, G, I.
